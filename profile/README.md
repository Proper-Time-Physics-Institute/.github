# Proper-Time-Physics-Institute

Research on the **dual theory of relativity and quantum mechanics** (Gill et al.) —
a reformulation using *proper time* τ as the natural parameter, the positive-definite
Hamiltonian K = H²/(2mc²) + mc²/2, and the *collaborative speed* b = √(c²+u²).

## Topic repos
- **[quantum](../../quantum)** — Griffiths correspondence, Bethe–Salpeter precision spectroscopy, DRQM/Dirac verification
- **[electromagnetic](../../electromagnetic)** — Jackson canonical problems in proper time, Maxwell-equation verification
- **[relativistic-dynamics](../../relativistic-dynamics)** — GPS relativity, Mercury perihelion, classical-electron & thermodynamics verification

## Support repos
- **[commons](../../commons)** — unified bibliography, cross-topic synthesis, foundations corpus, paper pipeline
- **[pyphysics-mcp](../../pyphysics-mcp)** · **[precision-data-mcp](../../precision-data-mcp)** — MCP servers (installed via uv git-deps)
- **[animations](../../animations)** · **[podcasts](../../podcasts)** · **[branding](../../branding)** · **[tooling](../../tooling)** — shared content (git submodules)
